What AI, machine learning and LLMs actually are

"AI" is used for everything from spam filters to chatbots. Before running a model on your PC it helps to know exactly what the thing in the file is.

What you will learn

  • Place AI, machine learning, deep learning and LLMs in one picture
  • Explain what a "model" and a "weight" are
  • Explain why a language model is a next-word predictor and why that is enough to look intelligent
  • Explain why it makes things up

Four nested words

These four terms get mixed up constantly. They are nested, like Russian dolls.

TermMeaningExample
Artificial intelligenceAny software that does something we would call intelligent. The widest ring.A chess engine, a route planner, a chatbot
Machine learningAI where the rules are learned from examples instead of written by hand.A spam filter trained on millions of emails
Deep learningMachine learning that uses many-layered neural networks.Image recognition, speech to text
Large language model (LLM)A deep-learning model trained on huge amounts of text to continue text.GPT, Claude, Gemini, Llama, Qwen

A model is a function with knobs

Forget AI for a moment. A function takes numbers in and gives numbers out. f(x) = 3 × x turns 2 into 6. A model is a function too, but instead of one number (the 3) it has billions of adjustable numbers called weights or parameters. You do not set them by hand. A training process sets them automatically by showing the model many examples and nudging every weight a tiny bit each time the answer is wrong.

Concept: weights

Weights are the learned numbers inside a model. A "9B model" has about 9 billion of them. The file you download is essentially just those numbers, plus a little metadata. There is no database of text inside and no internet connection needed to use it.

What an LLM does

An LLM has one job: given some text, score every possible next piece of text. Type "The capital of France is" and the model gives a high score to " Paris" and a very low score to " banana". A program then picks one piece, adds it to the text, and asks again. Repeat a few hundred times and you have a paragraph.

That is the whole mechanism behind every chatbot you have used. Everything else (answering questions, writing code, following instructions) emerges from getting extremely good at this one prediction task on a huge amount of text. To predict the next word in a physics textbook well, the model has to pick up physics. To predict the next line of Python, it has to pick up Python.

Concept: predict, pick, repeat

The model never writes a whole answer at once. It produces one small piece, appends it, and runs again. This is why long answers take time and why a model cannot "go back and fix" what it already wrote.

Why models make things up

Because the job is "produce plausible continuations", not "look up the truth". If the training text rarely mentioned a fact, the model still has to say something, and the most plausible-sounding thing is often wrong. This is called hallucination. Smaller models hallucinate more. The fix is not a better prompt alone. It is giving the model the facts to work with (lesson 6.3) and checking what it says.

Knowledge cutoff

A model only knows what was in its training text, up to a certain date. A local model has no idea what happened last week unless you tell it. The cloud chat apps get around this by adding web search. A local model can too, but only if you connect it.

Check yourself

What is physically inside a model file?

  1. A compressed copy of the internet
  2. A database of sentences it looks up
  3. Billions of learned numbers (weights) and some metadata

There is no text database. The knowledge is spread across the weights, which is why a model can be wrong and cannot cite where it learned something.

Why can a model that only predicts the next word still answer questions and write code?

  1. It secretly runs a search engine
  2. Predicting text well on a huge amount of data forces it to absorb facts and patterns
  3. It has a separate module for each task

Good prediction needs understanding of the content. Instruction-following is added on top with extra training (lesson 5.1).
