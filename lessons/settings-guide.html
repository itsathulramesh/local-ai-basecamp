Settings that matter: load options and sampling

The settings panel looks intimidating until you notice that it has two halves: how the model is loaded into memory, and how the next word is chosen. Learn both and you can tune any model.

What you will learn

  • Explain every important load setting and when to change it
  • Explain temperature, top-k, top-p and min-p, and see their effect
  • Choose sensible starting values for different tasks
Names can differ by version

LM Studio and Ollama rename and reorganise settings from time to time. The ideas below stay the same.

Part 2: sampling (how the next word is chosen)

Remember that the model outputs a score for every possible next token. Sampling is the rule that turns those scores into a pick. If you always chose the top token the writing would be flat and repetitive. A little randomness makes it natural.

Temperature

Temperature scales the scores before they become probabilities. Low temperature sharpens the differences, so the top choice dominates. High temperature flattens them, so unlikely words get a real chance. At zero the model is deterministic.

Top-k, top-p and min-p

These trim the list of candidates before picking:

  • Top-k keeps only the k most likely tokens.
  • Top-p (nucleus) keeps the smallest set of tokens whose probabilities add up to p, for example 0.9.
  • Min-p removes tokens whose probability is below a fraction of the best token's. It adapts nicely to how confident the model is.

Starting values

TaskTemperatureOthers
Facts, extraction, code, data tasks0 to 0.3Defaults are fine
General chat and Q&A0.6 to 0.8Top-p 0.9 to 0.95
Creative writing and brainstorming0.9 to 1.1Min-p 0.05
Use the model card

Many model authors publish recommended sampling values on the model's page (some thinking models especially). Start there, since they tested those values.

Repeat penalty

Discourages the model from repeating the same words. A small value (around 1.05 to 1.1) fixes loops. Large values make the text strange.

System prompt

The system prompt is an instruction the model sees before the conversation: its role, tone and rules. It is part of the context, so a long system prompt costs context length. Keep it short and specific.

Presets

Once you find values you like, save them as a preset in LM Studio. Make one per use: "precise", "chat", "creative". Switching presets is faster than retyping.

Concept: change one knob at a time

Ask the same question five times at each setting and watch what changes. Log it in your notes. This habit is what separates tuning from guessing.

Check yourself

You need the model to extract the same fields from a thousand invoices reliably. Which temperature?

  1. 1.2
  2. 0 to 0.3
  3. 2.0

Extraction wants consistency. Low temperature picks the most likely answer.

What does a higher temperature do?

  1. Flattens probabilities, giving unlikely tokens a bigger chance
  2. Makes the model run hotter
  3. Makes the context longer

Temperature reshapes the probability distribution.

Which setting increases how much context fits in the same VRAM?

  1. Top-k
  2. Repeat penalty
  3. KV cache quantization

An 8-bit cache is about half the size of a 16-bit one.
