Evaluate your fine-tune honestly

A falling loss proves the model learned your training data. It does not prove the model got better at the job, or that it did not get worse at everything else. This lesson builds a small, honest evaluation you can run in minutes.

What you will learn

  • Compare base and fine-tuned models on held-out examples
  • Run a blind A/B test where you are the judge
  • Check for forgetting with a regression set
  • Use automatic checks and an LLM judge carefully

Four kinds of check

CheckMeasuresCost
Automatic checksFormat: valid JSON, required keys, length limits, banned phrasesFree and instant
Blind A/B by you"Which answer is better?" with model names hiddenYour time. The gold standard.
LLM as judgeA strong model scores answers against a rubricCheap, but biased (it favours longer answers and its own style)
Regression setDid general ability survive? 20 to 30 unrelated questionsMinutes

Serve both models

Import the base model's GGUF and your fine-tune's GGUF into Ollama (lesson 8.2), for example as base and mine. Use the same quantization for both so quantization does not bias the comparison.

The script: ab_eval.py

"""Blind A/B test of two models on test.jsonl, plus optional automatic checks."""
import json, random, sys
from openai import OpenAI

client = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")
A, B = "base", "mine"
rows = [json.loads(l) for l in open("data/test.jsonl", encoding="utf-8")][:20]


def ask(model, messages):
    r = client.chat.completions.create(model=model, messages=messages, temperature=0.2, max_tokens=600)
    return r.choices[0].message.content.strip()


def auto_check(text):
    """Edit for your task: return a list of problems."""
    problems = []
    if len(text) > 1500:
        problems.append("too long")
    return problems


score = {A: 0, B: 0, "tie": 0}
for i, row in enumerate(rows, 1):
    prompt = [m for m in row["messages"] if m["role"] != "assistant"]
    answers = [(A, ask(A, prompt)), (B, ask(B, prompt))]
    random.shuffle(answers)                      # hide which model is which
    print(f"\n===== {i}/{len(rows)}  QUESTION =====\n{prompt[-1]['content']}")
    print(f"\n----- reference answer -----\n{row['messages'][-1]['content']}")
    for k, (_, text) in enumerate(answers, 1):
        print(f"\n----- answer {k}  {auto_check(text)} -----\n{text}")
    pick = input("\nBetter answer? [1/2/t] ").strip().lower()
    winner = "tie" if pick == "t" else answers[int(pick) - 1][0] if pick in {"1", "2"} else "tie"
    score[winner] += 1
print("\nRESULT:", score)

Run it on Windows with the openai package installed. Do not peek at which is which until the end.

How much difference is real?

With 20 questions, 11 to 9 is a coin flip. 16 to 4 is a real signal. If the result is close, add more questions before deciding. Small differences on small test sets are mostly noise.

The regression set

Write 20 to 30 questions unrelated to your fine-tune: explain a concept, write a short Python function, summarise a paragraph, simple arithmetic, a question it should say "I don't know" to. Run both models. A clear drop on these means catastrophic forgetting (lesson 9.1): fewer epochs, a lower learning rate, or mix general examples into your data.

Signs of overfitting in the answers

  • It copies phrases or whole answers from the training data.
  • Every answer has the same length and opening, even when that does not fit.
  • It applies your format to questions where it makes no sense.
  • It invents details in the confident style of your training answers.

LLM as judge, carefully

For larger test sets you can ask a strong model to grade answers against a short rubric ("correct, follows the format, no invented facts, 1 to 5"). Shuffle answer order, hide model names, and spot-check its judgements against your own on 10 examples. If you use a cloud model as the judge, remember that your test data is sent to it.

Lab
  1. Import base and fine-tuned GGUFs into Ollama with identical quantization.
  2. Run ab_eval.py on 20 test examples. Record the score.
  3. Run your regression set on both.
  4. Write a three-line verdict in your notes: better at the task? worse at anything? keep or retrain?

Check yourself

Your fine-tune wins 11 to 9 on 20 questions. What can you conclude?

  1. It is clearly better
  2. Not much. That is within noise, so test more questions.
  3. The base model is better

Small margins on small sets are not reliable evidence.

Why hide which answer came from which model?

  1. So your expectations do not bias your judgement
  2. To save time
  3. Ollama requires it

People favour the model they hope will win. Blinding removes that.
