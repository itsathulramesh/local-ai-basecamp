NVIDIA driver, CUDA and checking that the GPU works

Most "my GPU is not being used" problems come from the driver. This lesson gets the foundations right and explains the CUDA jargon that confuses everyone.

What you will learn

  • Install or update the NVIDIA driver
  • Read the output of nvidia-smi
  • Know when you need the CUDA Toolkit and when you do not
  • Watch VRAM use live while a model runs

Driver first

The driver is the software that lets Windows and apps talk to the card. For LM Studio and Ollama, a reasonably current driver is all you need. Ollama's Windows documentation lists NVIDIA driver 551.61 or newer as the minimum, and newer cards such as the RTX 50 series need much newer drivers anyway, so simply update to the latest.

On your PC
  1. Open the NVIDIA app (or GeForce Experience) and let it install the latest Game Ready or Studio driver. Either works for AI.
  2. Or download directly from nvidia.com/Download by choosing your card.
  3. Restart if asked.

Check it with nvidia-smi

Open Windows Terminal or PowerShell and run:

nvidia-smi

You get a table. The parts to read:

  • Driver Version: what is installed.
  • CUDA Version: the highest CUDA version this driver supports. It does not mean CUDA is installed.
  • Memory-Usage: for example 1200MiB / 12288MiB, meaning used and total VRAM. Windows and your browser already use some.
  • GPU-Util: how busy the GPU is. It jumps while a model generates.

To watch it update once a second while you chat with a model:

nvidia-smi -l 1
Concept: you will see the model in VRAM

Load a model and run this command in another window. Memory-Usage jumps by roughly the model size plus its context cache. This is the quickest way to confirm the model is really on the GPU, and you will use it to check the calculators in module 3.

CUDA, cuDNN and the toolkit: what you need

What you want to doInstall CUDA Toolkit?
Run models with LM Studio or OllamaNo. They ship their own GPU libraries.
Train or run models with PyTorch from pipNo. The PyTorch download bundles the CUDA runtime it needs. You only need a recent enough driver.
Compile llama.cpp or other CUDA code yourselfYes. Install the Toolkit from NVIDIA.
Do not install everything "just in case"

Beginners often install several CUDA versions and end up with confusing conflicts. Install only what the task in front of you requires.

If the GPU is not being used

  • Update the driver and restart.
  • Close other heavy VRAM users such as games, video editors and many browser tabs with hardware acceleration.
  • On a laptop, make sure the app is set to use the NVIDIA GPU, not the integrated one.
  • Check the app's runtime setting. In LM Studio this is the CUDA runtime under the runtimes settings. In Ollama the server log shows which GPU it found.
  • Check that the model is not so large that the app chose CPU instead.

Check yourself

nvidia-smi shows "CUDA Version: 13.0". What does that tell you?

  1. CUDA Toolkit 13.0 is installed
  2. Your driver supports up to CUDA 13.0
  3. Your GPU has 13 GB of VRAM

It is the maximum supported by the driver, not an installed toolkit.

Do you need to install the CUDA Toolkit to use LM Studio?

  1. Yes, always
  2. Yes, but only version 11
  3. No, it ships its own libraries

You only need the driver. The Toolkit is for compiling CUDA code yourself.
