Activation steering: change behaviour without training

Add a direction to the residual stream while the model runs and you can make it shorter, more formal or more cheerful, with no training and no prompt. This lesson builds a steering vector in Python, then applies one to a GGUF with llama.cpp.

What you will learn

  • Build and apply a steering vector, and sweep layer and strength
  • Measure the intended effect and the side effects
  • Create and use llama.cpp control vectors on a GGUF
  • Choose between prompting, steering and fine-tuning

The idea

Take the direction from lesson 10.1 (verbose minus concise). While the model generates, add α × v to one layer's output at every token. Positive α pushes toward verbose, negative toward concise. Nothing on disk changes, and removing the hook restores the original model.

Lab: steer.py

"""steer.py: apply the verbose-vs-concise vector and sweep layer x strength."""
import torch
from dirkit import load, chat, generate

TEST = ["What is a CPU cache?", "How do airplanes fly?", "What is a reverse proxy?"]
NEUTRAL = "The committee met on Tuesday to review the budget and agreed to postpone the vote until March."


class Steer:
    """Add alpha * v to one decoder layer's output while active."""
    def __init__(self, layer, v, alpha):
        p = next(layer.parameters())
        self.layer, self.v, self.alpha = layer, v.to(p.device, p.dtype), alpha
    def hook(self, module, inputs, output):
        if isinstance(output, tuple):
            return (output[0] + self.alpha * self.v, *output[1:])
        return output + self.alpha * self.v
    def __enter__(self):
        self.h = self.layer.register_forward_hook(self.hook)
    def __exit__(self, *exc):
        self.h.remove()


@torch.no_grad()
def neutral_loss(model, tok):
    ids = tok(NEUTRAL, return_tensors="pt").to(model.device)
    return float(model(**ids, labels=ids.input_ids).loss)


tok, model = load()
diff = torch.load("verbose_minus_concise.pt")          # index i = output of layer i - 1
n = len(model.model.layers)
base = neutral_loss(model, tok)
print("layer alpha  mean_len  side_effect  sample")
for L in (n // 4, n // 2, 3 * n // 4):
    for alpha in (-4.0, -2.0, 0.0, 2.0, 4.0):
        with Steer(model.model.layers[L], diff[L + 1], alpha):
            outs = [generate(model, tok, chat(tok, q), 160) for q in TEST]
            side = neutral_loss(model, tok) - base
        mean_len = sum(k for _, k in outs) / len(outs)
        print(f"{L:5d} {alpha:+5.1f} {mean_len:9.1f} {side:+11.3f}  {outs[0][0][:60]!r}")

How to read the results

  • Mean length should rise with positive α and fall with negative α at a good layer.
  • Side effect is how much more surprised the model is by a neutral sentence. It usually starts rising before the text visibly breaks, which makes it an early warning.
  • Read the samples. Length can rise because the model starts repeating itself. A result only counts if the text is still good.
  • Middle layers usually steer best. Past a certain strength, coherence collapses suddenly.
Your own direction

Swap the instructions for a formal-versus-casual pair, or plain-English versus jargon. Then compare your new vector with the verbosity one using cosine similarity (torch.nn.functional.cosine_similarity). Below about 0.3 means a genuinely different direction.

Steering a GGUF with llama.cpp

LM Studio and Ollama do not currently expose steering, but llama.cpp's own server runs the same GGUF files and supports control vectors. A control vector is a small GGUF holding one direction per layer, and it must come from the same model (same width and layers).

1. Make one with llama-cvector-generator

The tool runs paired prompts through the model, takes positive-minus-negative differences at each layer, and condenses them (PCA by default, or --method mean). Prompt files have one prompt per line, written in the model's raw chat format with newlines escaped as \n. Generate them from the tokenizer so the template is exact:

"""make_cvec_prompts.py: write positive/negative prompt files for llama-cvector-generator."""
from transformers import AutoTokenizer
tok = AutoTokenizer.from_pretrained("Qwen/Qwen3-0.6B")    # the same model as your GGUF
QS = ["What is DNS?", "Why is the sky blue?", "What is TLS?", "How do vaccines work?"]  # use 50+
def fmt(system, q):
    t = tok.apply_chat_template([{"role": "system", "content": system}, {"role": "user", "content": q}],
                                tokenize=False, add_generation_prompt=True, enable_thinking=False)
    return t.replace("\n", "\\n")
with open("positive.txt", "w", encoding="utf-8") as p, open("negative.txt", "w", encoding="utf-8") as n:
    for q in QS:
        p.write(fmt("Answer in one short sentence.", q) + "\n")
        n.write(fmt("Answer at length with detail and examples.", q) + "\n")
./build/bin/llama-cvector-generator -m model-Q8_0.gguf \
  --positive-file positive.txt --negative-file negative.txt -ngl 99 -o concise.gguf

2. Apply it

./build/bin/llama-server -m model-Q8_0.gguf \
  --control-vector-scaled concise.gguf:0.8 --control-vector-layer-range 8 20 \
  --host 127.0.0.1 --port 8081

Negative scales push the other way. The server speaks the same OpenAI-style API as lesson 6.2. Flag spellings have changed between versions (some older docs show the scale after a space), so run llama-server --help and trust what it prints. The tools are in llama.cpp's Windows release downloads, or you can build them in WSL2 (lesson 9.6).

Steering vs prompting vs fine-tuning

PromptingSteeringFine-tuning
Changes weights?NoNoYes (or adds an adapter)
Cost to createMinutesAn hourHours, data, a GPU
Can a user override it?EasilyNot from the promptNot from the prompt
Best forMost tasksOne behaviour axis: tone, length, personaNew formats and skills
Main riskIgnored, injectedIncoherence at high strengthForgetting, overfitting

Check yourself

Mean answer length rises at α = +4, but samples repeat the same phrase. Is the steering a success?

  1. Yes, the number went up
  2. Yes, if the side-effect metric is below 1
  3. No. The text broke, so lower α or try another layer.

Always read the outputs, not only the metric.

Can a control vector made from a 0.6B model steer a 9B model?

  1. No. It must come from the same model.
  2. Yes, any model works
  3. Only at scale 1.0

Widths and layers differ, and directions are model-specific.
