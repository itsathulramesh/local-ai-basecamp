Command cheatsheet

The commands and numbers you will want to hand. Everything here appears somewhere in the course.

Check your system

nvidia-smi                                   # GPU, driver, VRAM use
nvidia-smi -l 1                              # refresh every second
nvidia-smi --query-gpu=name,driver_version,memory.total,memory.used,temperature.gpu --format=csv
systeminfo | findstr /C:"Total Physical Memory"
python --version ; git --version

Python environment

python -m venv .venv
.venv\Scripts\Activate.ps1
pip install openai requests
pip list
deactivate
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned   # if activation is blocked

Ollama

ollama run MODEL          # chat (downloads if needed)
ollama run MODEL --verbose   # show speed
ollama pull MODEL
ollama list
ollama ps                 # loaded models and CPU/GPU split
ollama show MODEL
ollama stop MODEL
ollama rm MODEL
ollama create NAME -f Modelfile
# API: http://localhost:11434   OpenAI-style: http://localhost:11434/v1
# Env vars: OLLAMA_MODELS, OLLAMA_CONTEXT_LENGTH, OLLAMA_HOST (careful)

LM Studio command line

lms ls                    # downloaded models
lms get MODEL             # search and download
lms load MODEL --gpu=max --context-length=8192
lms ps                    # loaded models
lms unload --all
lms server start          # API at http://localhost:1234/v1
lms server stop
lms log stream

Hugging Face

pip install -U "huggingface_hub[cli]"
hf auth login
hf download REPO FILE --local-dir .\models

Memory maths

WhatFormula or value
Weights (GB)parameters in billions × bits per weight ÷ 8
Bits per weightF16 16 · Q8_0 ≈ 8.5 · Q6_K ≈ 6.6 · Q5_K_M ≈ 5.7 · Q4_K_M ≈ 4.9 · Q3_K_M ≈ 3.9 · Q2_K ≈ 3.4
KV cache per token2 × layers × KV heads × head size × bytes (2 for 16-bit, about 1 for 8-bit)
OverheadAbout 1 to 1.5 GB plus Windows ≈ 0.5 to 1 GB
Speed ceilingmemory bandwidth (GB/s) ÷ active weights (GB); real ≈ 55 to 75%
Tokens vs words1 token ≈ 0.75 English words ≈ 4 characters

Training (inside WSL2)

wsl --install                         # in PowerShell, once
nvidia-smi                            # inside Ubuntu: must show your GPU
python3 -m venv .venv && source .venv/bin/activate
pip install --upgrade unsloth unsloth_zoo
python make_dataset.py --notes notes --out data --model MODEL_ID   # on Windows, LM Studio server running
python train_lora.py 2>&1 | tee train.log
python ab_eval.py                     # blind A/B against the base model

Export with llama.cpp

git clone https://github.com/ggml-org/llama.cpp && cd llama.cpp
cmake -B build && cmake --build build --config Release -j     # add -DGGML_CUDA=ON for GPU tools
python convert_hf_to_gguf.py MERGED_DIR --outtype bf16 --outfile model-BF16.gguf
./build/bin/llama-quantize model-BF16.gguf model-Q4_K_M.gguf Q4_K_M
python convert_lora_to_gguf.py LORA_DIR --base-model-id BASE_ID --outtype f16 --outfile lora-F16.gguf
lms import model-Q4_K_M.gguf --copy --user-repo me/mine        # LM Studio (PowerShell)

Steering and editing

./build/bin/llama-cvector-generator -m model.gguf --positive-file pos.txt --negative-file neg.txt -o vec.gguf
./build/bin/llama-server -m model.gguf --control-vector-scaled vec.gguf:0.8 --host 127.0.0.1
./build/bin/llama-server -m base.gguf --lora-scaled lora-F16.gguf:0.7 --host 127.0.0.1
python ablate.py --pos pos.txt --neg neg.txt --test test.txt --layer 12 --out edited-model
