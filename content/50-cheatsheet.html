Memory maths

WhatFormula or value
Weights (GB)parameters in billions × bits per weight ÷ 8
Bits per weightF16 16 · Q8_0 ≈ 8.5 · Q6_K ≈ 6.6 · Q5_K_M ≈ 5.7 · Q4_K_M ≈ 4.9 · Q3_K_M ≈ 3.9 · Q2_K ≈ 3.4
KV cache per token2 × layers × KV heads × head size × bytes (2 for 16-bit, about 1 for 8-bit)
OverheadAbout 1 to 1.5 GB plus Windows ≈ 0.5 to 1 GB
Speed ceilingmemory bandwidth (GB/s) ÷ active weights (GB); real ≈ 55 to 75%
Tokens vs words1 token ≈ 0.75 English words ≈ 4 characters

Export with llama.cpp

git clone https://github.com/ggml-org/llama.cpp && cd llama.cpp
cmake -B build && cmake --build build --config Release -j     # add -DGGML_CUDA=ON for GPU tools
python convert_hf_to_gguf.py MERGED_DIR --outtype bf16 --outfile model-BF16.gguf
./build/bin/llama-quantize model-BF16.gguf model-Q4_K_M.gguf Q4_K_M
python convert_lora_to_gguf.py LORA_DIR --base-model-id BASE_ID --outtype f16 --outfile lora-F16.gguf
lms import model-Q4_K_M.gguf --copy --user-repo me/mine        # LM Studio (PowerShell)

Steering and editing

./build/bin/llama-cvector-generator -m model.gguf --positive-file pos.txt --negative-file neg.txt -o vec.gguf
./build/bin/llama-server -m model.gguf --control-vector-scaled vec.gguf:0.8 --host 127.0.0.1
./build/bin/llama-server -m base.gguf --lora-scaled lora-F16.gguf:0.7 --host 127.0.0.1
python ablate.py --pos pos.txt --neg neg.txt --test test.txt --layer 12 --out edited-model
