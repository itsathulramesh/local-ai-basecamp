Every local AI user hits the same dozen problems. Here they are, with the fastest checks first.

What you will learn

  • Diagnose slowness, out-of-memory errors and strange output
  • Know where to find logs
  • Build a habit of changing one thing at a time
It is extremely slow (a few tokens per second)

Almost always the model is partly or fully on the CPU. Check nvidia-smi to see if VRAM rose. In Ollama run ollama ps and look at the processor column. Fix: lower the context length, use a smaller quantization, close other apps using VRAM, or choose a smaller model.

Out of memory, failed to load, or crash

The model plus cache exceeded VRAM. Lower the context, enable 8-bit KV cache, pick a smaller quantization, close games and video apps, and check that another AI app is not holding a model in memory.

The GPU is not used at all

Update the NVIDIA driver and restart. On a laptop confirm the app runs on the NVIDIA GPU. In LM Studio check the selected runtime is CUDA. Look at the logs for lines about GPU detection.

Gibberish, repeating text or odd tokens at the start

Often a wrong chat template, or the wrong kind of model (a base model used as a chatbot). Use the instruct version and let the app auto-detect the template. A very low-bit quantization (Q2 or Q3) can also produce gibberish. Try Q4 or higher.

It ignores my long document or my instructions

Context is too small and the start was cut off. Raise the context length or shorten the input. Put the key instruction at the end as well as the beginning.

It loops or repeats itself

Raise the repeat penalty a little (1.05 to 1.1), lower temperature, or check the model card's recommended settings. Some thinking models loop when sampling is wrong.

It makes up facts

This is expected, especially for small models. Supply the facts in the prompt, ask it to say "I do not know" when unsure, and verify anything important.

Answers start with a long "thinking" section

You loaded a reasoning model. You can usually hide or collapse it in the UI, and some models allow a switch or prompt flag to turn thinking off for speed.

Disk is full

Models are 2 to 50 GB each. In LM Studio delete unused ones from My Models. In Ollama use ollama rm. Consider moving the model folder to a larger drive.

The PC gets hot and loud

Generation uses the GPU heavily. Make sure the case has airflow, and on a laptop use a hard surface and plug in the charger. Lower the GPU power limit if needed.

Where the logs are

  • LM Studio: Developer tab, then the log view.
  • Ollama: %LOCALAPPDATA%\Ollama contains app.log and server.log.

A calm method

  1. Write down exactly what you did and what happened.
  2. Check VRAM, GPU use and logs before guessing.
  3. Change one setting, retest, and note the result.
  4. Search the exact error text. Chances are someone solved it.

Check yourself

A model that used to run fast is now at 3 tokens per second after you raised the context from 8K to 64K. Most likely cause?

  1. The model weights got corrupted
  2. The internet is slow
  3. The cache grew and some layers spilled to the CPU

Larger context means a bigger cache, which can push the model over the VRAM limit.
