The tier map

These are practical ranges for a typical 4-bit "Q4_K_M" version of a model (lesson 3.1 explains that term) with a moderate context and 16 GB of system RAM. "Fast" means fully on the GPU. "With offload" means part of the model runs from system RAM: it works, at a few tokens per second. More RAM raises the offload ceiling.

Laptops with a 4 GB card

On most laptops the NVIDIA GPU does not drive the screen, so nearly all 4 GB is available for models. Plug in the charger: on battery the GPU slows down a lot.

Concept: dense vs mixture-of-experts (MoE)

A dense model uses all its parameters for every token. A mixture-of-experts model has many specialist "experts" but only activates a few per token. A name like "35B-A3B" means 35 billion total, 3 billion active. Two consequences: all 35 billion must still be stored (so memory is sized by the total), but each token only reads the active part, so it can generate much faster than a dense model of the same size.

Example models in each size class (late 2026)

Several recent guides published in October 2026 recommend these as sensible fits. Names change quickly, so treat them as examples of a size class and check what is newest.

  • 8 GB: Qwen3.5 9B at Q4_K_M (about 5.6 GB), Gemma 4 E4B.
  • 12 GB: Gemma 4 12B at Q4 (about 7 GB), Qwen3.5 9B at higher quality.
  • 16 GB: gpt-oss-20b (about 12 GB in its native 4-bit format), Gemma 4 12B at Q8.
  • 24 to 32 GB: 27B to 35B models such as Qwen's 27B dense and 35B-A3B mixture-of-experts, Gemma 4 26B and 31B.
No big GPU? You are not locked out

CPU-only and small-VRAM machines can still learn everything in this course using 1B to 4B models. They are surprisingly capable for summaries, rewriting, extraction and learning how it all works. For training later, rented cloud GPUs are cheap per hour (lesson 9.3).

Check yourself

"Qwen3.5-35B-A3B" is a mixture-of-experts model. Which number sets how much memory you must have?

  1. 3 billion (active)
  2. 35 billion (total)
  3. The context length only

All experts must be stored. Only the active ones are read for each token, which helps speed, not memory.

With 8 GB of VRAM, which is the most sensible first choice?

  1. A 7B to 9B model at Q4
  2. A 70B model at Q8
  3. A 30B dense model at FP16

A 7B to 9B Q4 model is about 4 to 6 GB, leaving room for context.
